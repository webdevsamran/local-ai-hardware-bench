# ADR-0007 — Enterprise control plane stays separate and optional

**Status:** Proposed (Phases E/F, not implemented; see
`docs/enterprise/overview.md`)

**Context.** The task specifies an optional enterprise control plane
(REST API, PostgreSQL, object storage, agents) that must not make the
community CLI require a server or database.

**Decision.** The community core keeps zero server dependency and remains
fully offline. Any control plane ships as a separate package/repository
under its own license with an explicit, versioned data contract to the
core's published artifacts (schema-validated results, bundles, provenance).
Detection-only adapters never claim benchmark capabilities.

**Consequences.** License boundaries stay unambiguous; the OSS core remains
useful without enterprise services; the data contract gives the control
plane a clean ingestion path.
