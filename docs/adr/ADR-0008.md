# ADR-0008 — HashRouter for the static GitHub Pages UI

**Status:** Accepted (implemented in `web/src/App.tsx`)

**Context.** The leaderboard is deployed to GitHub Pages under
`/local-ai-hardware-bench/` as a static bundle. `BrowserRouter` deep
links 404 there: Pages serves only static files with no SPA fallback, and
a Vite `base` path alone does not fix direct URL entry or refreshes.

**Decision.** Use `HashRouter`. Routes live under `#/...`, so every deep
link resolves to `index.html` without any server cooperation, keeping the
community deployment zero-infrastructure.

**Consequences.** URLs carry a `#` segment (cosmetic); in-page anchor
scrolling needs explicit handling. If the project later ships a real SPA
fallback (own server or the enterprise control plane), switching to
`BrowserRouter` is a single-router change isolated in `App.tsx`.
