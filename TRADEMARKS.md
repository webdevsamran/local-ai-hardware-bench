# Trademarks and Branding Policy

## Source code vs. project branding

The **source code** in this repository is licensed under the Apache
License 2.0 — anyone may use, modify, and redistribute it, including
commercially.

The **project name and branding** ("AIHWBench", "Open Local AI Hardware
Benchmark", and associated logos) are separate from the code license.
This document explains how they may be used.

> Note: as of this writing no trademark registration has been filed or
> granted for these names. This policy is a statement of intent, not a
> claim of registered rights.

## What forks may do

Forks and derivatives are welcome. A fork may:

- Describe itself honestly, e.g. "a fork of AIHWBench" or "based on
  AIHWBench".
- Use the names nominatively to refer to this project (e.g. "compatible
  with AIHWBench result schema 1.0").

A fork must NOT:

- Present itself as the official AIHWBench project or imply endorsement.
- Publish results under the AIHWBench name in a way that suggests they
  come from this project's validated dataset.
- Use the project's logos or certification marks.
