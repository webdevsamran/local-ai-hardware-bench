# ADR-0002 — Canonical metric vocabulary

**Status:** Accepted (implemented in `0a6e6e5`)

**Context.** Metric names diverged across `metrics.py` (`latency_stddev_ms`,
`itl_mean_ms`, `energy_per_token_joules`), `schemas.py`/`domain.py`
(`stddev_latency_ms`, `itl_ms`, `energy_joules_per_token`) and exporter
columns (`latency_p50_ms`). Unknown fields validated fine and vanished from
SDK parsing, silently losing data.

**Decision.** `aihwbench/metrics.py` owns one `METRIC_REGISTRY`: canonical
id → unit/family/legacy aliases. Readers (`resolve_metric`) resolve
canonical-first with alias fallback; the aggregator emits canonical names
only; exporters, SDK and domain read through the registry. Schema vocabulary
is the canonical id source of truth.

**Consequences.** Old documents read losslessly (aliases honored); new
emissions are schema-aligned; unknown fields no longer silently disappear.
A future `result-2.0` formal schema keys off the same ids.
