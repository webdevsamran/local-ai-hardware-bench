# Competitive analysis

AIHWBench measures *local inference performance across runtimes and hardware*, with one load generator driving every backend so two numbers differ only in what they measured. Most projects below are runtimes or serving engines that report their own numbers; the distinction is whether the measurement is comparable across them.
