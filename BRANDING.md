# Branding

## Project identity

- **Name:** AIHWBench (Open Local AI Hardware Benchmark)
- **Tagline:** Vendor-neutral, reproducible benchmarking of local AI
  runtimes across CPUs, GPUs, NPUs, and edge accelerators.
- **Tone:** Engineering-grade, honest, vendor-neutral. No hype, no
  unverifiable claims.

## Naming rules

- Use "AIHWBench" for the project and CLI (`aihwbench`).
- Use "AIHWBench Community" when distinguishing the open-source core
  from planned commercial offerings.
- Never imply certification, endorsement, or partnership that does not
  exist. See [TRADEMARKS.md](TRADEMARKS.md).

## Visual identity

No official logo exists yet. Contributions of a simple, vendor-neutral
logo are welcome via PR (SVG preferred, must be original work licensed
under Apache-2.0 or CC0).

## Writing style

- Prefer measured statements: "measured on X" over "blazing fast".
- Always state what was NOT measured (null metrics).
- Cite the exact command, runtime version, and hardware when quoting
  numbers.
