# Examples

- `configs/models.json` — model tiers and the default workload definition.
- `scripts/install-ollama.ps1` — one-command Ollama setup on Windows.
- `scripts/run-smoke-benchmark.ps1` — pull the smoke model and run a full
  benchmark + validation end-to-end.

A real example result lives in `results/published/` with its markdown
report in `docs/reports/`.
