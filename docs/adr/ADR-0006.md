# ADR-0006 — Frontend routing for static GitHub Pages hosting

**Status:** Proposed (Phase D, not yet implemented)

**Context.** The SPA uses `BrowserRouter` while the production build is
served under `/local-ai-hardware-bench/` with no SPA fallback. Deep links
(`/hardware/<fp>`, `/results/<runId>`, …) 404 on refresh.

**Decision.** Switch to `HashRouter` for the statically hosted community
site so deep links survive refresh without server-side rewrites. When an
authenticated API mode is added (Phase E), re-evaluate `BrowserRouter` +
a real server with SPA fallback and keep the router choice behind the
data-source abstraction.

**Consequences.** URL format changes from `/hardware/x` to `/#/hardware/x`;
stability for shared links; no server configuration needed on Pages.
