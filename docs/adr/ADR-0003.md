# ADR-0003 — Fail-closed publishing pipelines

**Status:** Accepted (implemented in `4583444`)

**Context.** Frontend data generation WARN-skipped unreadable JSON, and the
dataset/snapshot loaders silently dropped invalid files, so CI could publish
a subset without failing.

**Decision.** Publishing/CI paths fail closed: `load_results(strict=True)`
raises `DatasetLoadError`; `generate_frontend_data.py` validates schema on
every file and exits 2 on corruption; snapshots abort on any unreadable
member. Tolerant loading remains available (defaults / `--tolerant`) for
exploratory local use.

**Consequences.** Corruption is impossible to publish silently. Local
exploration is unaffected. CLI gained `export --strict`.
